# Risk Aversion and Flexible Learning: Optimal Asymmetric Signals under Limited Attention

Code for the bachelor thesis of Leonard Heidegger, University of St. Gallen (2026),
supervised by Prof. Dr. Michèle Müller-Itten. It reproduces every figure and numerical
result in the thesis.

The R code is in the folder `thesis_code_R` (base R only, no packages needed).
Set the working directory to that folder and run, for example,
`source("reproduce_numbers.R")`. See `thesis_code_R/README.md` for details.
